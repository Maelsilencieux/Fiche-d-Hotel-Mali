# SafeStay Mali

- `backend/`  — API Node.js/Express/MongoDB (voir `backend/README.md`)
- `frontend/` — Next.js 15 (voir `frontend/README.md`)

Démarrage : lancer MongoDB, puis `cd backend && npm i && cp .env.example .env && npm run dev`, et dans un autre terminal `cd frontend && npm i && cp .env.local.example .env.local && npm run dev`.
Compte superadmin créé au premier démarrage : voir `SUPERADMIN_EMAIL` / `SUPERADMIN_PASSWORD` dans `backend/.env`.
